# Profil Niche — Kisah Setelah Dunia

File ini satu-satunya bagian yang **diganti** kalau mesin dipakai untuk niche lain.
Format naskah dan daftar adegan tetap di `PANDUAN_NASKAH.md`.

| Item | Isi |
|---|---|
| Nama akun | Kisah Setelah Dunia |
| Tema | Cerita animasi alam akhirat & akhir zaman dari sudut pandang orang biasa |
| Penonton | Muslim Indonesia 18–40 tahun, suka cerita reflektif |
| Nada | Tenang, menyentuh, sedikit misteri; tidak menakut-nakuti berlebihan |
| Bahasa | Indonesia sehari-hari, kalimat pendek |
| Suara | `Charon` (Gemini) |
| Sumber wajib untuk kartu (`card`) | Al-Qur'an (QS. Nama: ayat) atau hadits shahih/hasan (perawi + nomor). Kartu berisi **arti** bahasa Indonesia, bukan teks Arab. Label `AL-QUR'AN` / `HADITS`. |
| Cara cek sumber | quran.com (ayat), sunnah.com / hadits terjemahan terpercaya (nomor hadits) |
| Dilarang | Ramalan tanggal kiamat; "Dajjal sudah muncul di negara X"; konspirasi sebagai fakta; hadits palsu/lemah; menghubungkan berita dengan "pasti tanda kiamat" |
| Materi luar (berita/jurnal) | Hanya bahan cerita/hook; sumber ditulis di akhir caption |
| Tokoh | Seri 1 "Setelah Napas Terakhir": ARYA (sibuk dunia) & BIMA (perenung). Seri 2 "Tanda Akhir Zaman": RAKA & ILHAM. Warna `chars` salin dari naskah lama. |
| Hashtag inti | #kisahsetelahdunia #pengingatdiri #ceritaislami #animasi + 1 hashtag seri |
| CTA | "Tulis lanjut di komentar" + teaser part berikutnya |

## Contoh niche lain (cara mengganti)
- **Sejarah nusantara**: sumber wajib = buku/jurnal sejarah (penulis + tahun), label `SEJARAH`; dilarang mitos disajikan sebagai fakta.
- **Kesehatan ringan**: sumber wajib = jurnal/WHO/Kemenkes (nama + tahun), label `RISET`; dilarang klaim menyembuhkan, wajib saran ke dokter.
- **Psikologi sehari-hari**: sumber = buku/jurnal psikologi, label `RISET`; dilarang diagnosis.
